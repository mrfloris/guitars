---
title: Pedalboard Project
description: Building a first guitar pedalboard from no pedals and no board hardware, with room for a parallel experiment board later.
---

This project starts honestly: there is no pedal collection and no finished board yet. The goal is to understand the signal chain, power, noise, switching, and physical layout before buying a pile of boxes that do not work well together.

## Board One: The Main Rig

The first board should work well with the Marshall daily driver and cover a useful range without becoming difficult to operate.

| Stage | Effect ideas |
| --- | --- |
| Feel and input | Wah, compressor |
| Gain | Overdrive, RAT-style distortion |
| Modulation | Chorus, phaser, flanger |
| Space | Reverb and possibly delay |
| Utility | Tuner, clean power, sensible cable routing |

A conventional starting order would place touch-sensitive and gain effects early, modulation after gain, and time-based effects later. The final order remains an experiment, especially if a parallel path proves more useful than one long serial chain.

## Board Two: The Experiment Rig

A smaller second board could run in parallel or act as a test bench. It would make it possible to try odd combinations without dismantling the dependable main board every time curiosity wins.

## All-In-One Alternative

The [NUX MG-50Li](https://nuxaudio.com/product/mg50li/) is being researched as a multi-effects and routing alternative. Its expression pedal support, external effects loops, MIDI, computer connection, headphones, wireless option, and dual-output possibilities make it relevant even if individual pedals remain the long-term goal.

## Build Journal Plan

The journal will follow the project from an empty floor to a working board: initial requirements, first layout, power and cabling, noise problems, experiments, what was returned or replaced, and the final Marshall settings that make it all worthwhile.
